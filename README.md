# devops-capstone-project

## Project Overview
This is the DevOps Capstone Project for developing a customer account microservice for an e-commerce website. The service provides a well-formed REST API that allows other microservices to perform CRUD (Create, Read, Update, Delete) operations on customer accounts.

## Features to Implement
* Read an account from the service
* Update an account in the service
* Delete an account from the service
* List all accounts in the service
* Containerize the microservice using Docker
* Deploy the Docker image to Kubernetes
